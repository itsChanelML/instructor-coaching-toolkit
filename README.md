# Instructor Coaching Toolkit

An observation rubric, a feedback template, and a train-the-trainer pipeline
for technical instruction — plus a fully worked example showing all three
applied to a real session.

**Part of a three-piece portfolio on technical instruction:** [AirClaude](https://github.com/itsChanelML/airclaude) (build it) · [Engineer Agent Adoption Workshop](https://github.com/itsChanelML/engineer-agent-adoption-workshop) (teach it) · **Instructor Coaching Toolkit** (this repo — coach the instructor)

## Why this exists

[AirClaude](https://github.com/itsChanelML/airclaude) and
[engineer-agent-adoption-workshop](https://github.com/itsChanelML/engineer-agent-adoption-workshop)
are the "build it" and "teach it" halves of a technical instruction
portfolio. Neither one demonstrates **coaching other instructors** —
through observation and feedback, and running a train-the-trainer program.

This is that third piece — and it's deliberately not written in the
abstract. `WORKED_EXAMPLE.md` applies the rubric to an actual delivery of
the workshop in the sibling repo, grounded in that workshop's own
documented failure modes rather than a generic "here's what feedback could
look like" filler.

## Contents

- [`OBSERVATION_RUBRIC.md`](OBSERVATION_RUBRIC.md) — eight dimensions,
  a four-level scale, and why the dimensions are never averaged into one
  number
- [`FEEDBACK_TEMPLATE.md`](FEEDBACK_TEMPLATE.md) — Situation → Behavior →
  Impact → Suggestion, with worked strength and gap examples
- [`TRAIN_THE_TRAINER_PROGRAM.md`](TRAIN_THE_TRAINER_PROGRAM.md) — the
  four-stage pipeline (shadow → co-teach → solo, observed → ongoing
  calibration) a candidate moves through to get certified on a given
  session
- [`WORKED_EXAMPLE.md`](WORKED_EXAMPLE.md) — a full Stage 3 observation of a
  (fictional) candidate delivering `engineer-agent-adoption-workshop`, including the
  actual rubric scores, SBI feedback, and the certification decision

A reference page version of the rubric and worked example is published
[here](https://claude.ai/artifact/17zv89JvCM7kz4awi84Nt6).
